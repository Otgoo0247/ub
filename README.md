# Улаанбаатар хотын хүн ам, өрх, гишүүнчлэлийн дашбоард

Улаанбаатар хотын 9 дүүрэг, 204 хорооны хүн ам, өрх, нягтрал, гишүүдийн тоо ба бүтцийг газрын зураг, график, хүснэгтээр харуулна. Build алхамгүй, цэвэр статик сайт тул Vercel дээр шууд байршина.

## Vercel дээр байршуулах

### А. Vercel CLI-аар (хамгийн хурдан)

```bash
npm i -g vercel
cd ub-dashboard
vercel          # эхний удаа: нэвтэрч, төслийн нэрээ сонгоно → preview холбоос гарна
vercel --prod   # үндсэн (production) хаяг руу гаргана
```

Асуулт гарвал анхдагч хариултыг сонгоно. Тохиргоо `vercel.json`-д байгаа тул build command, output directory-г өөрчлөх шаардлагагүй.

### Б. GitHub-аар (автомат шинэчлэлттэй)

1. Хавтасны **доторх** бүх файлыг (`vercel.json`, `public/`, `tools/`, `.gitignore`, `.vercelignore`) GitHub репогийн үндэс рүү оруулна. Репог **Private** болгохыг зөвлөж байна — `public/data/` дотор гишүүдийн тоо бий.
2. vercel.com → **Add New… → Project** → репогоо **Import** хийнэ.
3. Тохиргооны дэлгэц дээр заавал шалгана:
   - **Root Directory**: `./` (хоосон). `tools` сонгогдсон байвал **Edit** дарж `./` болгоно — эс бөгөөс сайт 404 өгнө.
   - **Framework Preset**: `Other`.
   - Build/Output/Install командуудыг хоосон орхино (`vercel.json` удирдана).
4. **Deploy**. Цаашид `main` салбар руу push хийх бүрт автоматаар шинэчлэгдэнэ.

> **GitHub-ийн вэбээр файл оруулахад** нэр нь цэгээр эхэлсэн файлууд (`.gitignore`, `.vercelignore`) ихэвчлэн орхигддог. Тэдгээрийг **Add file → Create new file** ашиглан гараар үүсгэнэ.

> **Хандалтын тухай (заавал уншина уу):** Vercel-ийн production хаяг анхдагчаар хэн ч нээх боломжтой бөгөөд `public/data/` доторх файлуудыг шууд татаж болно. Энэ сайтад хороо бүрийн гишүүдийн тоо орсон тул нийтэд нээлттэй байршуулахаас өмнө Project → Settings → **Deployment Protection**-ийг асааж, зөвхөн эрх бүхий хүмүүст нээнэ үү (зарим сонголт төлбөртэй багцад л байдаг).

## 404 алдаа гарвал

Vercel → төсөл → **Settings → Build and Deployment**: **Root Directory** хоосон (`./`), **Framework Preset** `Other` байгаа эсэхийг шалгаад **Deployments → ⋯ → Redeploy** хийнэ. Build амжилттай ч `/` хаяг 404 өгч байвал бараг үргэлж Root Directory буруу байдаг.

## Орон нутагт турших

`fetch` ашигладаг тул `index.html`-ийг шууд давхар дарж нээвэл ажиллахгүй. Жижиг сервер ажиллуулна:

```bash
cd ub-dashboard
python3 -m http.server 8000 -d public   # эсвэл: npx serve public
# http://localhost:8000
```

## Өгөгдлийг шинэчлэх

### Хүн ам, өрх, гишүүд (шинэ нэгтгэл ирэх бүрт)

```bash
cd ub-dashboard/tools
pip install -r requirements-data.txt
python build_excel.py --excel /зам/2026.11.19_Negtgel.xlsx --ages /зам/2026.11.19_Negtgel_V1.xlsx
```

`--ages` файлаас «18-25», «Сонгуулийн нас 18+ дээш» баганыг авна (хүн амын тоо хоёр файлд ижил байх ёстой; өгөхгүй бол `--excel` файлаас хайна). Excel-д хоёр хуудас байх ёстой: «Өрх, хүн амын тоо, хороогоор» (Дүүрэг, Хорооны нэр, Нийт өрхийн тоо, Хүн амын тоо) ба «Гишүүнчлэл» (2-р мөр толгой). Скрипт хороо бүрийг газрын зурагтай тулгаж, таарахгүй мөр байвал зогсоно. Дараа нь дахин deploy хийнэ.

**Нууцлал.** Скрипт регистр, нэр, утас, MEMBER_ID-г огт уншдаггүй. Гаралтад зөвхөн нэгтгэсэн тоо гарна: хот, дүүрэг, хороо бүрийн гишүүдийн тоо ба задаргаа. 5-аас цөөн гишүүнтэй хүрээний задаргааг хоосон үлдээнэ (`MIN_GROUP`), мөн дээд хүрээний дүнгээс хасаж тооцоолж болох хүрээг нэмж нууна. Excel файлыг өөрийг нь репо эсвэл `public/` руу хэзээ ч бүү хуул (`.gitignore` хаасан).

## Нэвтрэлт

Сайтын **бүх хэсэг** нэвтрэлтийн ард байна. Хоёр тусдаа холбоостой:

| Холбоос | Хэн | Юугаар | Юу харна |
|---|---|---|---|
| `/login` | Гишүүд (намын 350 гишүүн ба урилгаар бүртгүүлэгчид) | Нэвтрэх нэр + санамсаргүй нууц үг (админ /admin → «Нэвтрэх эрх»-өөс үүсгэнэ; бүртгүүлэгчид автоматаар) | Дашбоардын статистик, «Миний мэдээлэл» (/me), ирц, зарлал |
| `/admin-login` → `/admin` | Админ | `AUTH_USERNAME` + `AUTH_PASSWORD` | Бүгд: дашбоард, гишүүдийн нэрс, «Намын гишүүд», «Бүртгэл», админ хэсэг |

`middleware.js` эрхгүй хүнийг тохирох нэвтрэх хуудас руу шилжүүлэх эсвэл 401 буцаана. Нэрсийн `/api/members`, бүртгэлийн `/api/registrations`, `/admin` зөвхөн админд. Админы нэвтрэлт 12 цаг, гишүүнийх 7 хоног.

Админ, гишүүний сешн тус тусдаа тул нэг хөтөч дээр зэрэг нэвтэрч болно; «Гарах» зөвхөн тухайн сешнийг хаана. Админ дашбоардыг `/?as=admin` хаягаар бүрэн эрхээр харна. Нууц үгийг MEMBERS_KEY-ээр шифрлэж хадгалдаг тул админ дахин харж, Excel-ээр татаж тарааж болно.

### Vercel дээрх тохиргоо (заавал)

Vercel → төсөл → **Settings → Environment Variables** (Production, Preview, Development):

| Нэр | Утга |
|---|---|
| `AUTH_USERNAME` | Нэвтрэх нэр |
| `AUTH_PASSWORD` | Нууц үг — **12-оос доошгүй тэмдэгт** (богино бол хэн ч нэвтрэхгүй) |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Урилгын бүртгэлийн сан. Upstash for Redis-ийг холбоход Vercel **өөрөө** нэмнэ (доорх «Урилгаар бүртгүүлэх»). |
| `MEMBERS_KEY` | `MEMBERS_KEY.txt` / `tools/members.key` доторх 64 тэмдэгт — гишүүдийн нэрсийг тайлна |

Хадгалсны дараа **Deployments → ⋯ → Redeploy**. Хувьсагч дутуу бол сайт хаалттай хэвээр үлдэнэ (нээлттэй болохгүй).

- **Нууц үг солих:** `AUTH_PASSWORD`-ийг солиод Redeploy — бүх хүн шууд гарч, дахин нэвтэрнэ.
- Хуучин `MEMBERS_PASSWORD` хувьсагч хэрэггүй болсон; устгаж болно.
- **GitHub репо:** сайт хамгаалагдсан ч `public/data/` дахь нэгтгэсэн тоонууд (хороо бүрийн гишүүдийн тоо г.м.) репо дээр харагдана. Репогоо **Private** болгоно уу.

## Гишүүдийн нэрс

Газрын зургийн хажууд гишүүдийн нэрс шууд харагдана: юу ч сонгоогүй үед хотын бүх гишүүн, дүүрэг сонгоход тухайн дүүргийнх, хороо сонгоход тухайн хорооных. Нэр, нас, хүйс, үүр, хөдөлгөөн, анкетын хувь гарах ба нэрээр хайж болно (сайтад нэвтэрсэн хүнд). Регистр, утас, MEMBER_ID огт харагдахгүй. Нэрс `private/members.enc` файлд AES-256-GCM-ээр шифрлэгдсэн; тайлах түлхүүр (`MEMBERS_KEY`) зөвхөн Vercel-д хадгалагдана. Түлхүүрийн файлыг GitHub руу **ХЭЗЭЭ Ч** бүү оруул.

### Гишүүний дэлгэрэнгүй ба урилгын код

Шүүлтүүрийн мөрийн баруун талын **«Бүртгэл»** товч бүх гишүүдийн жагсаалтыг тусдаа цонхонд нээнэ (дүүрэг, хороо, нэрээр шүүнэ; «Урьсан» баганад урилгаар бүртгүүлсэн хүний тоо). Нэрийн ард байгаа **«Дэлгэрэнгүй»** товчийг дарахад цонх нээгдэж нас, хүйс, төлөв, үүр, хөдөлгөөн (огноотой), анкет бөглөлт болон **урилгын код** гарна. Код гишүүн бүрт тогтмол (жишээ нь `7KQ2M-X9D4P`); Excel-ээ шинэчилсэн ч өөрчлөгдөхгүй.

- **Холбоос хуулах** — `https://<таны-сайт>/invite?c=КОД` холбоосыг хуулна. Мессеж, Facebook, Viber гэх мэтээр явуулна.
- **SMS-ээр / И-мэйлээр** — урилгын бэлэн мессежтэй апп нээгдэнэ. Утсан дээр **Илгээх…** товч гарч, Messenger гэх мэт апп сонгоно.
- Холбоосыг нээсэн хүн **нэвтрэхгүйгээр** урилгын хуудсыг харж, бүртгэлийн маягт бөглөнө (доор). Түүнд урьсан гишүүний товч нэр (Х. Нэр), дүүрэг, урилгын код л харагдана; дашбоардын бусад хэсэг хаалттай хэвээр.
- Цонхонд «Энэ урилгаар бүртгүүлсэн: N хүн» гарна.
- Код нь `members.key`-ээс хамаардаг: `--rotate-key` хийвэл бүх урилгын код шинэчлэгдэж, тараасан холбоосууд ажиллахаа болино.

### «Намын гишүүд» — бүртгүүлэгчдийг Excel-ээр татах

Шүүлтүүрийн мөрийн баруун талд **«Намын гишүүд»** (Бүртгэлийн урд) товч бий. Дарахад 350 гишүүн, тус бүрийн урилгын кодоор бүртгүүлсэн хүний тоо гарна (хамгийн олон урьсан нь дээрээ). Дүүрэг, хороо, нэрээр шүүх, «Зөвхөн бүртгүүлсэн хүнтэй» сонголттой.

- Мөр бүрийн **Excel** товч тухайн гишүүний урилгаар бүртгүүлсэн хүмүүсийг `.xlsx` файлаар татна: овог, нэр, төрсөн огноо, нас, хүйс, утас, хаяг, бүртгүүлсэн огноо, өөрийн урилгын код, урьсан хүн.
- **Бүгдийг Excel-ээр** — бүх бүртгүүлэгч нэг файлд (урилгаар бүртгүүлсэн хүний урьсан хүмүүс ч «(бүртгүүлэгч)» тэмдэгтэй орно).
- Excel файлыг хөтөч дотроо үүсгэнэ (гадны сан, сервер шаардлагагүй); зөвхөн админд харагдана.

### Урилгын мод

«Энэ урилгаар бүртгүүлсэн: N хүн» (админы гишүүний цонх) болон «Миний урилгаар бүртгүүлсэн» (/me) мөрийн баруун талд **«Урилгын мод»** товч бий. Дарахад гишүүн → түүний урилгаар бүртгүүлсэн хүмүүс → тэдний урьсан хүмүүс … гэж үе үеэр нь салаалсан мод нээгдэнэ: салааны зузаан = тэр хүнээс доош хэдэн хүн, өнгө = үе (1-р үе улаан, 2 цэнхэр, 3 ногоон, 4 шар, 5+ саарал). Томруулах, чирэх, «бүтнээр харах» товчтой; хулгана аваачихад бүртгүүлсэн огноо, шууд урьсан, нийт доор нь гарна.

- Админ ямар ч гишүүний бүх модыг харна. Бүртгүүлэгч /me дээр зөвхөн **өөрөөсөө доошх** модыг харна; модонд нэр, бүртгүүлсэн огноо л харагдана (утас, хаяг — зөвхөн шууд урьсан хүмүүсийн жагсаалтад).

### Урилгаар бүртгүүлэх

Урилгын хуудасны маягт: **Овог, Нэр, Төрсөн он сар өдөр, Хүйс, Утасны дугаар** (8 оронтой, `+976` байж болно), **Хаяг** — «Улаанбаатар хот» бол дүүрэг → хороо (204 хороо), «Аймаг» бол аймаг → сум (21 аймаг, 330 сум), мэдээлэл ашиглах **зөвшөөрөл**.

Бүртгүүлсэн хүмүүс урьсан гишүүнийх нь «Дэлгэрэнгүй» цонхны доод хэсэгт гарна (овог нэр, утас, хүйс, төрсөн огноо ба нас, хаяг, бүртгүүлсэн огноо), «Бүртгэл» жагсаалтын «Урьсан» баганад тоо нь харагдана.

**Сан холбох (нэг удаа):**
1. Vercel → төсөл → **Storage** → **Create Database** (эсвэл Marketplace) → **Upstash for Redis** → үнэгүй багц → **Create**.
2. **Connect Project** → `ub-dashboard`-ыг сонгоно. `KV_REST_API_URL`, `KV_REST_API_TOKEN` автоматаар нэмэгдэнэ.
3. **Deployments → Redeploy**. Сан холбогдоогүй үед урилгын хуудас «Бүртгэл түр хаалттай» гэж харуулна.

**Хамгаалалт:**
- Бүртгэл бүр `MEMBERS_KEY`-ээс гаргасан түлхүүрээр AES-256-GCM шифрлэгдэж хадгалагдана — Upstash-ийн самбарт нэр, утас ил харагдахгүй. Жагсаалтыг зөвхөн дашбоардад нэвтэрсэн хүн харна.
- Хүчинтэй урилгын код заавал; нэг утсаар нэг л удаа; нэг IP-ээс цагт 10 оролдлого; нэг урилгаар 200 хүртэл бүртгэл; ботын далд талбар.
- Хаягийн жагсаалтыг `python tools/build_address.py` шинэчилнэ (хороо `public/data/khoroo.csv`-ээс, сумыг скрипт дотор).
- `MEMBERS_KEY`-г солибол өмнөх бүртгэлүүдийг тайлах боломжгүй болно.

### Гишүүнээр нэвтрэх ба өөрийн хуудас (/me)

`/login` дээр гишүүн өөрийн кодоо оруулаад дашбоард руу орно; «Миний мэдээлэл» товчоор /me руу шилжинэ.

- Намын 350 гишүүн ба урилгаар бүртгүүлэгчид аль аль нь өөрийн урилгын кодоор нэвтэрнэ.
- Бүртгүүлмэгц «Бүртгэл амжилттай» → автоматаар **/me** руу шилжиж, **өөрийн шинэ урилгын код, холбоос** авна. /me дээр өөрийн мэдээлэл, урилгын холбоос (хуулах, SMS, и-мэйл, илгээх), **өөрийн урилгаар бүртгүүлсэн хүмүүс** харагдана. 
- Сешн 7 хоног (`ub_member`), нэг IP-ээс цагт 20 оролдлого.

### Нэрсийг шинэчлэх

```bash
cd ub-dashboard/tools
python build_members_secure.py --excel /зам/шинэ_нэгтгэл.xlsx   # tools/members.key-г ашиглана
python build_excel.py --excel /зам/шинэ_нэгтгэл.xlsx            # нэгтгэсэн тоо
```

Дараа нь `private/members.enc` болон `public/data/*`-г репод шинэчилж deploy хийнэ.

### Нууц үг, түлхүүр солих

- **Нууц үг солих:** Vercel дээр `AUTH_PASSWORD`-ийг солиод Redeploy. Бүх нэвтрэлт шууд хүчингүй болно.
- **Түлхүүр солих** (алдагдсан гэж сэжиглэвэл): `python build_members_secure.py --excel … --rotate-key` → шинэ `members.key`-г `MEMBERS_KEY`-д хуулж, шинэ `members.enc`-ийг оруулаад Redeploy.

> Репо public хэвээр байвал шифртэй файл түүхэнд үлдэнэ. 256 битийн санамсаргүй түлхүүртэй тул тайлах боломжгүй ч репогоо **Private** болгохыг зөвлөж байна.

## Их, дээд сургуулийн цэг

Газрын зураг дээр цэнхэр цэгээр их, дээд сургууль, коллежийн байршил гарна. Хулгана аваачихад нэр, дүүрэг/хороо, гудамж, газрын талбай, эрхийн төрөл; дарахад тухайн хороо сонгогдоно. Цагаан (хөндий) цэг нь кадастрт нэр нь тодорхойгүй боловсролын газар — хамгийн ойрын сургууль, зайг нь харуулна. Домгийн доорх чагтаар асааж/унтраана — анхдагчаар унтраалттай (`uni=1` асаана).

Шинэчлэх: `python build_points.py --shp /зам/сургууль.shp` → `public/data/universities.csv`. Нэрийг кадастрын эзэмшигчийн нэр болон Google Maps-ийн байршилтай тулгаж тогтоосон (`confidence`: өндөр/дунд/бага).

### Газрын зургийн бөмбөлөг ба хөвөгч карт

- **Гишүүдийн бөмбөлөг:** хот харагдаж байхад дүүрэг бүрд, дүүрэг сонгоход хороо бүрд гишүүдийн тоо (хэмжээ = тоо). Хамгийн олон гишүүнтэй 3 нь цагаан дотортой улаан хүрээтэй. Дарахад тухайн газрыг сонгоно; давхцвал жижиг нь түр нуугдаж, томруулахад гарна. Домгийн «Гишүүдийн тоо (бөмбөлөг)» чагтаар унтраана (`bub=0`).
- **Хөвөгч карт:** дүүрэг/хороо сонгоход зургийн зүүн дээд буланд хүн ам, 18+, 18–25, гишүүдийн тоо ба хотод эзлэх хувийн баар; × нь сонголтыг цуцална.
- **KPI:** дүрс тэмдэг; 18+ ба 18–25-д хүн амд эзлэх хувийн цагираг.

### Их, дээд сургуулийн суралцагчид

«Их, дээд сургууль» чагттай үед газрын зургийн доор суралцагчдын хэсэг гарна: нийт, хүйс, диплом/бакалавр; 11 ерөнхий чиглэлийн график (эрэгтэй/эмэгтэй); нарийвчилсан чиглэлийн задгай хүснэгт. Өгөгдөл: `public/data/uni_students.csv` (82 мөр; нийлбэр нь «Бүгд» мөртэй — 128,498 — таарсан). Шинэчлэхдээ ижил багануудтай CSV-ээр солино.

## Суурь зураг

Газрын зургийн доор гудамж, барилга, гол мөрөн харагдах суурь зураг (base map) байна. «Суурь зураг» сонголтоор солино; «Будгийн тод байдал» гулсуураар хороодын өнгийг бүдгэрүүлж суурь зургийг илүү тод харуулна:

| Сонголт | Үйлчилгээ | Анхаарах нөхцөл |
|---|---|---|
| Цайвар | CARTO Positron / Dark Matter (харанхуй горимд автоматаар) | Арилжааны бус, сард ~75 000 хүртэл харагдалтад үнэгүй. Түүнээс их бол CARTO-гийн төлбөртэй эрх авна. |
| OpenStreetMap | tile.openstreetmap.org | Бага ачаалалтай сайтад зориулсан; [tile ашиглах журам](https://operations.osmfoundation.org/policies/tiles/)-ыг баримтална. |
| Хиймэл дагуул | Esri World Imagery | Esri-ийн [нөхцөл](https://www.esri.com/en-us/legal/terms/full-master-agreement)-ийг шалгана; албан ёсны хэрэглээнд ArcGIS бүртгэл шаардаж болно. |
| Байхгүй (анхдагч) | — | Гадны сервер рүү хандахгүй. Хуудас ингэж эхэлнэ. |

- Tile-ийг **үзэгчийн хөтөч** шууд татдаг тул tile үйлчилгээ үзэгчийн IP хаягийг хардаг. Дотоод сүлжээнд, гадагш хандахгүй ажиллуулах бол `public/js/config.js` дотор `basemap: false` болгоно.
- Зургийн баруун доод буланд эх сурвалжийн бичиг (attribution) автоматаар гарна; үүнийг хасаж болохгүй.
- Хил Web Mercator (EPSG:3857) проекцтой байх ёстой, `build_data.py` анхдагчаар ингэж гаргана. `--crs EPSG:32648` (UTM)-аар гаргавал суурь зургийн сонголт автоматаар нуугдана.
- Шинэ tile үйлчилгээ нэмэх бол `app.js` доторх `BASEMAPS`-д нэмж, `vercel.json`-ийн `Content-Security-Policy` → `img-src`-д хостыг нь нэмнэ.

## Шүүлтүүрийг холбоосоор хуваалцах

Сонгосон шүүлтүүр URL-д хадгалагдана, жишээ нь:

```
/?district=Баянгол&metric=gerpct
/?district=Хан-Уул&khoroo=HUD_21&metric=pop
/?level=district&metric=hhsize
/?district=Сүхбаатар&base=sat
/?uni=1
```

`metric`: `dens`, `pop`, `hh`, `hhsize`, `members`, `mem_rate`, `gerpct` · `base`: `carto`, `osm`, `sat`, `none` · `level`: `khoroo`, `district` · `uni`: `1`, `0`.

## Кодын тухай

`js/app.js` нь Claude дээрх дашбоардын `dash` API-аар бичигдсэн бөгөөд `js/dash-runtime.js` тэр API-г (өгөгдөл ачаалах, `calc`, `draw`, шүүлтүүр) статик сайтад хэрэгжүүлдэг. Шинэ эх өгөгдөл нэмэх бол `dash-runtime.js` доторх `SOURCES`-д бүртгэнэ, шинэ шүүлтүүр нэмэх бол `DEFAULTS` (сонголт хязгаартай бол `ALLOWED`)-д нэмнэ.
